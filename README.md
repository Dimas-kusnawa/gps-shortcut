A program that writes one line to `/output/entry.txt` (124 characters, inside the 200-character cap): the GPS's own excuse for sending the driver down the wrong road — the lake was not on its map, so technically it took a shortcut, and the fact that it ends in water is the map's problem, not mine.

## Run it

```sh
python3 main.py
```
